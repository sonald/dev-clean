How it works

One command. Undo anytime.

dev-cleaner clean
  • Finds build outputs and caches under the current folder.
  • Lets you pick from a keyboard list, then shows a summary.
  • Moves them to the trash when you press Enter.
dev-cleaner undo

Changed your mind? Restores the last batch exactly where it was.

Just looking? dev-cleaner scan lists findings without changing anything. Prefer a full-screen UI? dev-cleaner tui.

Why it's safe to run

Built for confident cleanup

Fast, ignore-aware scanning

Ripgrep-style parallel traversal finds candidates first, then sizes them in parallel. Only top-level targets are reported, never nested duplicates.

Undoable trash

Cleanups land in a trash batch. Undo restores it; purge frees the space.

Rule attribution

Every finding names the built-in, custom, gitignore or heuristic rule behind it.

Risk-aware defaults

Dependencies like node_modules and gitignore discoveries stay hidden unless you opt in.

CLI, TUI or macOS app

Same engine everywhere, including a native SwiftUI app (build from source).

Safety by design

It explains itself before it touches anything

  • Conservative by default. Folders with git-tracked files, recently modified or in-use projects, and anything marked .dev-cleaner-keep are skipped.
  • Provenance you can inspect. --explain shows the source, category, risk and confidence of each path.
  • Local only. Scanning, trashing and restoring all run on your machine.

Works with Mole

Mole cleans your Mac.
Dev Cleaner goes deep on your projects.

Mole handles system-wide cleanup: app caches, uninstall leftovers, System Data, installers. Dev Cleaner focuses on the build output inside your workspaces, with every removal explained and undoable. Run both.

Mole system

  • App, browser and dev-tool caches
  • Uninstall leftovers and System Data
  • Installer sweeps, disk treemap, live status
mo clean
+

Dev Cleaner projects

  • Undoable trash batches instead of permanent deletes
  • --explain shows the rule, risk and confidence behind each path
  • Any folder, any depth, on Linux, macOS and Windows
  • JSON plans and recommend --cleanup 10GB for scripts
